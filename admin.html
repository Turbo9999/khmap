還沒接上 Supabase

  1. 到 Supabase 建立專案（建議 Tokyo 區域）。
  2. SQL Editor 貼上 repo 裡的 supabase/schema.sql 執行，最後一行把自己的 email 加進 admins。
  3. Authentication → Users 新增同一個 email 的帳號並設定密碼。
  4. 把 Project URL 與 anon key 填進 config.js，推上 GitHub，Cloudflare Pages 會自動部署。
  5. 回到這頁登入，按「匯入初始資料」。

目前地圖讀的是 repo 內的 data/seed.json。
